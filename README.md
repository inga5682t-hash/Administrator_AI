# PharmAnalytic PRO (v1.0.0)

Интеллектуальная система управления аптечными запасами.

## Как запустить
1. Склонируйте репозиторий.
2. Откройте `index.html` в браузере.

## Функционал
- Парсинг Excel (.xlsx) без сервера.
- Автоматический расчет дефицита (на < 1.5 месяца).
- Поиск неликвидов (расход отсутствует > 3 месяцев).
- Контроль сроков годности (критические зоны: 30 и 90 дней).
- Экспорт списка закупок в Excel.
- Визуальный дашборд.

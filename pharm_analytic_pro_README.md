# 💊 PharmAnalytic PRO

Система интеллектуального анализа аптечных запасов для медицинских организаций.

## Функционал
- **Загрузка данных**: Поддержка Excel (xlsx, xls) и CSV.
- **Анализ дефицита**: Выявление позиций, запаса которых хватит менее чем на 1.5 месяца.
- **Поиск неликвидов**: Список товаров без движения более 3 месяцев.
- **Контроль сроков**: Отслеживание лекарств со сроком годности менее 90 дней.
- **Визуализация**: Интерактивные графики состояния склада.

## Структура проекта
- `index.html` — Основная страница интерфейса.
- `css/style.css` — Стили оформления.
- `js/app.js` — Логика анализа и визуализации.
